# Exact pins, not ranges.
#
# The serialised model is tied to the scikit-learn, numpy and joblib versions
# that produced it. With >= ranges, `docker compose build` installs whatever is
# newest on the day it runs, so two people building from the same commit can end
# up scoring with different libraries. That already happened here: the container
# resolved scikit-learn 1.9.1 against a model pickled by 1.9.0, which logs 202
# InconsistentVersionWarning lines on every load.
#
# Measured, that particular drift was harmless: SHAP values bitwise identical,
# classification agreement 100 percent, scoring deviation 1.11e-16. A larger
# jump would not be. Pinning removes the question.
#
# These versions are the ones this build was verified against end to end.
